# XAU/USD 14-Day Challenge Tracker

Open `index.html` in a browser.

Features:
- $60 -> $1,000 challenge target
- 14-day exponential target path
- 3 trade slots per day (editable)
- Daily target and per-trade target
- Suggested lot estimate based on a configurable $ move/trade
- Spread setting
- Trade P/L, lot size and Win/Loss/BE logging
- Daily notes
- 14-day overview
- Local browser storage so data persists on the same device/browser

Important: the lot estimate assumes 0.01 lot produces approximately $1 P/L for a $1.00 XAU/USD move. Confirm the exact contract specification with your broker before using it.
